# Máquina de Pelúcia — Windows

![Downloads](https://img.shields.io/github/downloads/walteramguntzel-debug/maquina-de-pelucia-windows/total?label=downloads&color=e0357a)

A garra de pegar bichinho, em **3D**, no seu computador. Mexa a garra, aperte **PEGAR** antes de o
tempo acabar e tente trazer uma pelúcia para a estante. **No computador o jogo é grátis e as moedas
também.**

## ⬇️ Baixar

**[Baixar para Windows (zip, 45 MB)](https://github.com/walteramguntzel-debug/maquina-de-pelucia-windows/releases/latest/download/MaquinaDePelucia-Windows.zip)**

## Como instalar

1. Baixe o zip acima.
2. Clique com o botão direito no arquivo → **Extrair tudo…**
3. Abra a pasta **Maquina de Pelucia** e dê dois cliques em **MaquinaDePelucia.exe**.

Não precisa instalar nada. Se o Windows mostrar *"O Windows protegeu o computador"*, clique em
**Mais informações → Executar assim mesmo** (o aviso aparece em todo programa novo que ainda não tem
muitos downloads).

**Precisa de:** Windows 10 ou 11 (64 bits).

## Como jogar

| Teclado e mouse | |
|---|---|
| Setas ou W A S D | mexem a garra |
| Espaço | PEGAR (e, entre uma rodada e outra, pôr a MOEDA) |
| V | troca a vista |
| Arrastar com o mouse | gira a câmera em volta da máquina |
| Esc | volta ao menu |

Pegou uma pelúcia? **Guarde na estante** ou **troque por moedas** — cada bichinho vale conforme o tipo e o
tamanho. Acabaram as moedas? Aperte **Pegar moedas**: no computador é de graça.

As pelúcias são **virtuais**: nenhum brinquedo físico é enviado.
